The Concept

Three Steps from Agent Prompt to Verified Deliverable

Separate creative content from deterministic engineering so every AI coding agent ships reliable reports on the first pass.

STEP 01 ~70% fewer tokens

Emit Only Semantic HTML

The agent writes just <main id="report-main"> with headings, KPI cards, charts, or Mermaid blocks—zero doctypes, head tags, or CSS resets.

<main id="report-main">...</main>
STEP 02 <100ms build

Assemble & Verify Automatically

harness.mjs repairs missing heading IDs, auto-detects only the CDNs actually used, injects 32 DaisyUI themes, and runs 5-breakpoint Playwright checks.

node skills/html-report/scripts/harness.mjs run fragment.html
STEP 03 Two-Way Loop

Live Preview & Visual Edit Mode

serve-report.mjs hot-swaps updates via Idiomorph with zero scroll loss. Click any element in Edit Mode to tweak styles or send a surgical edit prompt back to your agent.

node skills/html-report/scripts/serve-report.mjs report.html

Key Capabilities Built Into Every Deliverable

Engineered to eliminate token waste, layout hallucination, and broken CDN dependencies.

Deterministic Assembly (<100ms)

Zero-dependency Node engine validates fragments, repairs heading IDs and responsive wrappers, and stitches complete HTML in milliseconds.

32 DaisyUI Themes + OKLCH

Sticky navbar swatch picker defaulting to light. Pure JS OKLCH matrix math adapts Chart.js, Mermaid, and Grid.js palettes live.

On-Demand 17-CDN Power Stack

Only the libraries detected in your fragment are injected: charts, flowcharts, Leaflet maps, KaTeX math, Highlight.js, Reveal.js, and FullCalendar.

Cryptographic SRI & CSP

Core CDN scripts carry SHA-384 integrity hashes, anonymous cross-origin isolation, strict Content Security Policy, and no-referrer privacy headers.

Real-Time Datastar & Agent Bridge

Stream live task checklist morphs over SSE without page reloads and inspect or edit report blocks directly from the browser.

5-Breakpoint Verification

Playwright verification checks viewports from 375px mobile to 1536px desktop, catching horizontal overflow and dark/light contrast issues.
