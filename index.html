html-report — Publication-Grade HTML5 Reports for AI Coding Agents

html-report is an open, LLM-agnostic Agent Skill built with OpenSpec. It equips any AI coding agent (Antigravity, Claude Code, Cursor, Codex, OpenCode, Gemini CLI) to generate interactive, theme-adaptive, offline-downloadable, and Playwright-verified HTML5 reports and CSV dashboards.

GitHub Repository Open Standalone example.html Download example.csv Jump to CSV Interactive Demo

README — What html-report Offers

  • Non-Blocking 11-CDN Stack: Tailwind CSS, DaisyUI (all 32 themes), Lucide Icons, Alpine.js, Chart.js, Mermaid, Leaflet (Esri tiles), Grid.js, KaTeX, Marked, and Highlight.js (TypeScript & Kotlin).
  • Sticky DaisyUI Navbar: Report title on the left (navbar-start); auto-mapped h1/h2/h3 Contents dropdown, 32-theme color-swatch selector (synced with Chart.js, Mermaid & Grid.js dark mode), and icon-only offline HTML bundler on the right (navbar-end).
  • CSV-Backed Interactive Forms: Highlights CSV-driven sections (example.csv), starts empty until loaded, and pairs search + custom DaisyUI filters with a live Grid.js table and Chart.js chart underneath.
  • Horizontal Scrollbar Space Detection & Playwright Gate: Flags any element where scrollWidth > clientWidth across all 5 Tailwind breakpoints (sm–2xl) and verifies PDF export before delivery.

9.1 Frontend Example — TypeScript

TypeScript

Frontend UI state & theme contract highlighted with `language-typescript`:

// Frontend TypeScript Type & Theme Dispatcher
export type DaisyUITheme =
  | "corporate"
  | "dark"
  | "synthwave"
  | "dracula"
  | "nord";

export interface FrontendReportProps {
  readonly reportId: string;
  readonly title: string;
  readonly activeTheme: DaisyUITheme;
  readonly enableOfflineBundle: boolean;
}

export function applyFrontendTheme(
  props: FrontendReportProps
): string {
  document.documentElement.dataset.theme =
    props.activeTheme;
  return `Theme [${props.activeTheme}] active`;
}

// Backend Kotlin Domain Model & Service
package io.htmlreport.backend

data class ReportSnapshot(
    val id: String,
    val title: String,
    val cdnCount: Int = 11,
    val verifiedBreakpoints: List<String>
)

    fun buildSnapshot(title: String): ReportSnapshot {
        val breakpoints = listOf("sm", "md", "lg", "xl", "2xl")
        return ReportSnapshot(
            id = "rep-2026-q4",
            title = title,
            verifiedBreakpoints = breakpoints
        )
    }
}
