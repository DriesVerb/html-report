1-Click Agent Install Prompt
Install the html-report skill from https://github.com/DriesVerb/html-report.git by cloning it into ~/.agents/html-report, symlinking ~/.agents/html-report/skills/html-report into ~/.agents/skills/html-report (and ~/.gemini/config/skills/html-report if using Antigravity/Gemini), and installing Playwright in ~/.agents/html-report/skills/html-report/playwright. Then read skills/html-report/SKILL.md.

Why Leading Agent Workflows Rely on html-report

Built specifically to eliminate token waste, layout hallucination, and broken CDN links in autonomous LLM pipelines.

Deterministic Assembly (<100ms)

Agents output only high-value semantic tags. The zero-dependency Node engine validates, auto-fixes headings and tables, and builds complete HTML in under 100 milliseconds.

32 DaisyUI Themes + OKLCH

Navbar swatch picker with 32 official themes defaulting to light. Pure JS OKLCH engine calculates perceptual palettes that synchronize Chart.js, Mermaid, and Grid.js in real time.

17 Non-Blocking CDNs

Zero heavy npm build step. High-performance charts, architecture flowcharts, Leaflet maps, KaTeX equations, syntax highlighting, and FullCalendar grids load on demand.

Cryptographic SRI & CSP

All remote CDN assets carry SHA-384 cryptographic integrity hashes with anonymous cross-origin, strict Content Security Policy, and no-referrer privacy headers.

Real-Time Datastar Streaming

Stream live agent telemetry, task checklist morphs, and tool execution drawers directly into the browser over Server-Sent Events (SSE) without page reloads.

5-Breakpoint Verification

Playwright verification checks viewports from 375px mobile to 1536px desktop, flagging horizontal scrollbars (scrollWidth > clientWidth) with prescriptive auto-fixes.
