💡 Problem & Architecture Vision

In modern analytical reporting and dashboard authoring, users frequently need in-browser rich text notes, executive drafting, and formatted descriptions. In create.html, users describe their project via a basic 2-row textarea. For complex briefs requiring hierarchy, bulleted KPIs, and emphasis, a plain textarea lacks clarity, while forcing a heavy rich-text editor for simple 1-line queries creates friction.

❌ Current Limitations

  • No WYSIWYG Addon: The build pipeline lacks a native, zero-config rich text editor addon for reports.
  • Cramped Plain Input: "Tell what the board needs to show" is restricted to an unformatted plain textarea.
  • Unstructured Prompts: Complex formatting in the textarea cannot be styled with bullets or headings.
  • No Goal Persistence: Accidental reloads or navigations clear user-entered goals.

✅ Proposed Solution: Quill v2.0 + Dual-Mode Wizard

  • Section A Visual Component: Selectable "WYSIWYG Rich Text Editor (Quill)" addon in create.html.
  • Dual-Mode Switcher: Instant toggle between Simple (Textarea) and Complex (Quill Snow).
  • Bidirectional Synchronization: Edits in either mode mirror instantly to the other.
  • Automatic LocalStorage Persistence: Saves entered content and mode selection across browser sessions.
  • Markdown-Optimized Prompt Synthesis: Translates rich editor content into clean, token-efficient Markdown for LLMs.
