Key Design & Architectural Decisions

1

Dedicated Studio Navbar

Replaces individual top-level theme and download buttons with a standardized, clean navbar mirroring template-shell.html. Keeps Sections and Projects prominent.

2

Consolidated Settings Gear

Encapsulates theme swatch selection (32 DaisyUI themes), PWA installation triggers, and export actions inside a single #studio-settings-gear-btn dropdown to prevent visual noise.

3

Projects Directory & SemVer

Adds dynamic report discovery via GET /api/projects with category badges (OpenSpec Journey, Report, Benchmark, Dev) and SemVer tags, opening target reports directly in new browser tabs.
