Synthesized Turnkey Agent Reconnection Prompt

Live Preview

When the two-way bridge is unreachable, the report constructs this tailored prompt containing the exact document context and shell commands. The reader clicks the button below, pastes it into their agent, and the agent restores the connection. 

I am viewing an interactive publication report: "Turnkey AI Agent Reconnection" (implementation-progress.html).
This report features an active Two-Way AI Agent Bridge and Datastar live hypermedia, but the local dev server is currently offline.
Please restore the two-way agent bridge by starting the report dev server in the background:
node skills/html-report/scripts/serve-report.mjs implementation-progress.html --port 3000 --no-open
Keep this process running. The report will automatically detect the connection, update its live badges, and unlock interactive co-pilot queries.
