Turnkey AI Migration Prompt Pattern

When breaking changes occur, downstream library authors can copy this standardized prompt into any AI agent to automatically refactor their code.

<AI_MIGRATION_PROMPT> (Standardized Specification) Agent-Agnostic 
<AI_MIGRATION_PROMPT>
You are an expert AI refactoring assistant upgrading this codebase's `html-report` integration.
A breaking change was released. Follow these exact instructions to upgrade the project:

1. TARGET VERSIONS:
   - Upgrading `html-report` from v1.x to v2.x.
   - Read the official migration guide at docs/migrations/v1-to-v2.md.

2. MECHANICAL CODEMODS:
   - Search for deprecated CLI flag invocations:
     Replace `--old-flag <value>` with `--new-flag <value>`.
   - Search for JS import statements:
     Replace `import { oldFn } from "html-report"` with `import { newFn } from "html-report/build"`.
   - Update any configuration files:
     Verify `package.json` dependency points to `^2.0.0`.

3. VERIFICATION:
   - Run the project's build and test suites: `npm test` or `node --test`.
   - Ensure all reports compile with zero deprecation warnings.
</AI_MIGRATION_PROMPT>
