Precision CLI Flags Specification

Supported options for fine-grained script control and automated CI

Flag Type Default Description & Purpose
--timeout <ms> Integer 30000 Maximum wait time for navigation, selector waiting, and report readiness handshake.
--suites / --only Comma string all Runs only specified checks (e.g. responsive,themes,addons).
--grep <pattern> RegExp null Executes only checks or assertion steps matching the provided pattern.
--themes <list> Comma string all Tests specific DaisyUI themes (e.g. light,dark,cyberpunk,nord) rather than cycling 32 themes.
--viewports <list> Comma string all 5 Verifies named breakpoints (sm,md,lg,xl,2xl) or custom dimensions (e.g. 1920x1080).
--screenshots [dir] Path null Captures PNG snapshots for every tested breakpoint or immediately upon test failure.
--bail Boolean false Aborts the run immediately on the first failed check for rapid CI failure feedback.
--strict Boolean false Treats horizontal space warnings (data-insufficient-space) and console warnings as fatal errors.
--json <path> Path null Emits a structured JSON test execution report with failure traces and durations for agent diagnosis.
--color-contrast Boolean false Runs automated WCAG AA color contrast ratio audits on active themes.
--headed Boolean false Launches Chromium in visible UI mode for interactive visual inspection and debugging.
--quick / -q Boolean false Legacy shorthand: runs sm and lg breakpoints on light theme only without PDF export.
