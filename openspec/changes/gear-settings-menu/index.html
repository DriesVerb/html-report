Problem & Vision


The gear menu provides a single entry point for settings, but fully expanded lists cause unnecessary vertical scroll and clutter. Separating "Publishing" into an isolated section also causes redundant user flows. This plan organizes the menu with an "All Settings" modal hub, unexpanded collapsible sections, a unified "Download" section with built-in "Publish" switch, and eliminates the obsolete separate publishing section.




Key Delivered Goals
    

  • Added "All Settings" as the first option, opening a tabbed overview modal (Appearance, Download, AI, Editor).
    • 

  • Kept all options in the gear navbar dropdown unexpanded by default with DaisyUI disclosure collapse.
    • 

  • Preserved the unexpanded "Appearance" title with the live color palette preview badges.
    • 

  • Renamed "Export" to "Download", and placed the "Publish" switch as its first option followed by "Download as HTML".
    • 

  • Removed the standalone "Publishing" section to eliminate redundancy.
    • 



Prioritization Strategy Delivered
    

  • Priority 1: Section consolidation (Download title, Publish switch, remove standalone publishing) & unexpanded collapsible navbar sections.
    • 

  • Priority 2: "All Settings" top action & tabbed overview modal with two-way synchronization.
    • 

  • Priority 3: Keyboard accessibility, test suite updates, and documentation synchronization.
    • 










Architecture & Flow




Gear Dropdown Shell
Starts with #open-all-settings-btn. Dropdown sections use collapsible disclosure accordions unexpanded by default. Appearance header showcases active theme and 4-color dot swatches.


All Settings Modal
Full-featured modal with DaisyUI boxed tabs allowing deep configuration of Appearance, Download & Publishing, AI Bridge, and Editor tasks.
