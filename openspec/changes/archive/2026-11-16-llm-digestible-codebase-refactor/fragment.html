Two-Package Modular Architecture

Top-level entrypoints preserve public exports and delegate to focused domain sub-modules under lib/, routes/, and ordered browser chunks. 

flowchart LR
  Skills["skills/html-* shims"] --> Core["@html-report/core"]
  Skills --> Studio["@html-report/studio"]
  Studio -->|public exports| Core
  Core --> CoreLib["scripts/lib/{build,harness,publish}/"]
  Core --> CoreRt["assets/report-runtime.js <- runtime/*.js"]
  Studio --> StudioLib["scripts/lib/{tracker,datastar,scaffold,server,domain,preflight,mcp}/"]
  Studio --> StudioRoutes["scripts/routes/{static,projects,studio-files,agent-*,mcp,sse,publish}.mjs"]
  Studio --> StudioAssets["assets/{authoring-plugin.js <- authoring/*, create.html + create-studio/*}"]
