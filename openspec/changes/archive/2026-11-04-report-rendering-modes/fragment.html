Current Friction

Rendering modes were previously treated through loose boolean flags (printable, live, presentation). This led to unnecessary background servers for static reports and broken SSE or CORS fetch when interactive dashboards or live streams were opened as raw file:// URLs.

The 6 Distinct Modes

A formalized enum of 6 distinguishable modes: print, report, presentation, dashboard, working-report, and live-report. Each has an explicit contract for styling, navbar UI, and dev server orchestration.

Server Orchestration Rule

No Server for print and report (zero background overhead). Mandatory Dev Server (serve-report.mjs on port 3000) for dashboard, working-report, and live-report to enable SSE, live-reload, and artifact routing.

CLI Interface Pattern

Clean, expressive CLI arguments supporting explicit canonical modes and ergonomic aliases: 

# 1. Print (No server, generates PDF directly)
node skills/html-report/scripts/harness.mjs run frag.html --mode print --pdf
# 2. Standard Report (No server, static HTML deliverable)
node skills/html-report/scripts/harness.mjs run frag.html --mode report
# 3. Interactive Dashboard (Auto-runs dev server)
node skills/html-report/scripts/harness.mjs run frag.html --mode dashboard
# 4. Working Journey Companion (Runs localhost:3000 with md viewer)
node skills/html-report/scripts/harness.mjs run frag.html --mode working-report
# 5. Live Datastar Stream (Runs dev server with SSE streaming)
node skills/html-report/scripts/harness.mjs run frag.html --mode live-report

Architectural Guardrails

  • Zero Lingering Servers: CLI commands for static reports exit immediately upon assembly and verification without spawning zombie dev processes.
  • Single-Tab Auto-Reload: When dev server runs, SSE broadcasts refresh the existing browser tab instead of polluting the user's workspace with duplicate browser tabs.
  • Showdown Markdown Routing: In working-report mode, dev server auto-maps /proposal.md, /design.md, etc., directly to the active change folder.
  • Full Backward Compatibility: Existing flags (--printable, --live, --presentation) function transparently as aliases.
