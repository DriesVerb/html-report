PWA Engine Capabilities

Automated Web App Manifest

Outputs compliant W3C manifest.webmanifest with standalone display mode, multi-resolution icon map, categories, app shortcuts, and start URL scopes.

manifest.webmanifest

Zero-Dependency Service Worker

Pure ESM sw.js caching engine implementing Cache-First for static CDNs and Network-First for HTML navigation with instant offline fallback.

sw.js (Vanilla ESM)

Dynamic DaisyUI Theme-Color Sync

Seamlessly synchronizes <meta name="theme-color"> with any of DaisyUI's 32 themes, adapting desktop window borders and mobile status bars on the fly.

32 Themes Synced

Native Install Prompt Affordance

Intercepts beforeinstallprompt and lights up an Install App button in the DaisyUI navbar and Download dropdown menu for 1-click installation.

beforeinstallprompt

Live Offline Status Detection

Listens to window.online / offline events, displaying an elegant warning pill when the device loses connection, reassuring the user the report is cached.

navigator.onLine

Universal Report Converter CLI

generate-pwa.mjs converts any existing standalone HTML report into an installable PWA retroactively without regenerating the original document.

generate-pwa.mjs
