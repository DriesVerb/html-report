Architectural Honesty Repo Alignment Audit

Honest Trade-Off Analysis: Is Option 2 In Line With What We Try to Do?

An unfiltered engineering evaluation of how full inlining aligns with—and creates friction against—the core promises of html-report.

Where Option 2 Aligns (Strong Fit)

  • Preserves Zero node_modules: The inlining engine relies solely on node:fs and node:zlib. Not a single npm package is introduced.
  • Zero Agent Token Burn: The LLM still generates only 500 semantic tokens. The inlining step is 100% mechanical and deterministic in <15ms.
  • Bulletproof Archival: Delivers immortal reports that cannot be broken by future CDN domain shutdowns, internet censorship, or enterprise air-gaps.
  • Total OPSEC Compliance: Fulfills defense and banking requirements where zero outbound network requests are legally mandated.

The Honest Tensions (Real Costs)

  • Git Repo Bloat: Storing 20MB of minified vendor libraries directly in git slows down git clone and npx skills add for all users.
  • Destroys GitHub PR Diffs: A 40KB CDN report diffs cleanly in GitHub. A 2.5MB inlined report triggers "Diff too large to display" in pull requests.
  • Browser RAM Redundancy: Opening 20 reports in tabs forces the browser to load 20 separate copies of Chart.js/Mermaid (~50MB RAM) instead of 1 shared cache.
  • Tailwind JIT Penalty: Inlining cdn.tailwindcss.com inlines the full 350KB browser JIT compiler rather than pre-compiled atomic CSS.

The Strategic Synthesis (The Verdict)

"An Opt-In Superpower, Never the Destructive Default."

If Option 2 replaced the default behavior, it would compromise html-report's signature lightweight agility, 40KB file sizes, and clean Git diffs.

The winning architecture:

  • Keep CDN-First as Default for daily coding, agent workflows, and live dev server.
  • Provide --inline as an Opt-In Flag for air-gapped exports, executive delivery, and compliance archiving.
  • Use an on-demand vendor cache (downloaded once on first --inline call) to keep the initial repository clone ultra-lean.

Deterministic CLI Flags & Capabilities Specification

Command-line flags driving the deterministic inlining engine, compression, and verification gates.

Flag & Command Engine Component Deterministic Action Output Deliverable
--inline build-report.mjs
harness.mjs run		 Inlines all active CSS into <style> and JS into <script>, omitting external CDN links. Standalone report.html (100% portable)
--compress build-report.mjs Uses native node:zlib to generate companion Brotli and Gzip pre-compressed archives. report.html.gz + report.html.br (~350KB)
--vendor-dir <path> build-report.mjs Specifies custom offline asset directory (defaults to skills/html-report/assets/vendor/). Customized asset source
--offline / --air-gapped verify-report.mjs Playwright intercepts all network requests and aborts external calls. Asserts 0 network outbound under file:///. Zero-network test verdict
vendor-assets.mjs Sync Utility Downloads the 16 CDN libraries once and verifies SHA-256 integrity checksums against vendor-manifest.json. Local Asset Vault populated
