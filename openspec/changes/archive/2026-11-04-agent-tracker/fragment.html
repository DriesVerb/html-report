The Core: What We Want to Observe First

Before tackling background daemons and swarm trees, what are the fundamental questions every developer needs answered in real time?

The 4 Core Observation Pillars
Pillar 1
Agent Heartbeat & State

Instantly answers: "Is my agent alive?". Displays whether it is Thinking, Executing Tool, Waiting on User, Idle, or Error with a live running stopwatch.

Pillar 2
Current Active Action

Instantly answers: "What is it executing right this second?". Shows the exact tool name (e.g. run_command) and its primary target/command with real-time execution duration.

Pillar 3
Latest Reasoning / Intent

Instantly answers: "Why is it doing this?". Captures the latest high-level chain-of-thought summary so you understand the agent's immediate hypothesis and next steps.

Pillar 4
Recent Action Feed

Instantly answers: "What did it just finish?". Displays a clean chronological list of the last 5-10 actions with duration badges, exit codes, and success/error status.

### Architectural Design Pattern Requirements

Do NOT couple the tracker directly to Google Antigravity or any single LLM provider. Every LLM (Antigravity, Claude Code, OpenAI Codex) has its own payload shape; you must implement the **Facade + Strategy Pattern**:

1. **`AgentTelemetryStrategy` Interface** (`skills/html-report/scripts/agent-tracker.mjs`):
   - `providerId: string`
   - `displayName: string`
   - `canHandle(rawPayload): boolean`
   - `normalize(rawPayload): CanonicalAgentEvent`
2. **Concrete Strategies**:
   - `AgyTelemetryStrategy`: Parses Google Antigravity steps (`thinking`, `tool_calls: [{ call: { name, args } }]`).
   - `ClaudeCodeTelemetryStrategy`: Parses Anthropic Claude Code content blocks (`type: "tool_use"`, `type: "thinking"` / `thinking_delta`).
   - `CodexSwarmTelemetryStrategy`: Parses OpenAI Codex / Swarm chat completion chunks (`delta.tool_calls`, `reasoning_content`).
   - `GenericTelemetryStrategy`: Universal REST payload `{ state, activeTool, thought, recentHistory }`.
3. **`AgentTrackerFacade`**:
   - Unified entry point that accepts raw payloads, selects the active strategy, validates zero vendor-specific leakage, and emits the canonical `AgentHeartbeatState` to the dev server SSE stream (`/__datastar_stream__`).
