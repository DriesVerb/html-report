Edit Mode Two-Tier Fast-Patch Architecture

Because Assembly (buildReport()) and Idiomorph hot-swap already run in under 100 ms, speeding up Edit Mode focuses on the upstream hand-off: enriching the prompt from #agent-manifest, fixing multi-project path resolution on POST /__agent_edit__, and executing surgical fragment.html patches in-process with seamless CLI fallback.

Five Root Causes Resolved

1. Manifest-Enriched Prompt: buildEditPrompt() reads #agent-manifest for files.fragment, files.entry, mode, and theme, skipping manual build-report.mjs rebuild hints when live-watched.
2. Multi-Project /__agent_edit__ Routing: Replaces single-file targetFileName check with workspace-root containment so /projects/<slug>/index.html works even when the server started on create.html.
3. Deduplicated Dispatch + Fast Model: Fixes { prompt: scoped, systemPrompt: scoped } double-concatenation in AgentInferenceRouter and routes via aiConfig.model.
4. Surgical Fragment Fast-Patch: Slices the targeted #target.id / <section>, validates patches with lintFragment() + buildReport(), and falls back to CLI on mismatch.
5. Hot-Swap Preservation: Separates <head>/runtime signatures from <main> widget scripts to avoid unnecessary full browser reloads.
