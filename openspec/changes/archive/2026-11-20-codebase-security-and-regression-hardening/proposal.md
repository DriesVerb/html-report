# Proposal: Codebase Security & Regression Hardening

> **Change:** `codebase-security-and-regression-hardening` | **Journey Companion:** [index.html](index.html) | **Design:** [design.md](design.md) | **Tasks:** [tasks.md](tasks.md) | **Delta Specs:** [security-and-regression-hardening](specs/security-and-regression-hardening/spec.md)

## Why

A full codebase review of `@html-report/core`, `@html-report/studio`, `skills/*`, and documentation uncovered high-severity local build/server vulnerabilities alongside functional CLI/server regressions and documentation drift:

1. **Build & Inclusion Security**: `fetchFeedSnapshotSync()` executed `curl` via shell string interpolation (`execSync`) allowing OS command injection from untrusted URLs; `loadMermaidFileContent()` read `.mmd` targets without canonical workspace containment checks; and `#feed-registry` / `title` / `theme` / Markdown viewer / theme swatch / chat / project-card renderers contained HTML/script injection sinks.
2. **Dev Server CSRF, CORS & Stability**: Destructive and mutating routes (`/api/projects/delete`, `/api/create/synthesize`, `/api/agent/persona`, `/__agent_action__`, `/api/agent*`, `/mcp/messages`, `/api/mcp/csrf-token`, `/api/mcp/call-tool`, `/__datastar_stream__`) emitted `Access-Control-Allow-Origin: *` without `enforceLocalBridgeSecurity`; `server.mjs` threw uncaught `URIError` on invalid percent-encoded URLs; `static.mjs` exposed root dotfiles (`.env`, `.git/HEAD`); and POST handlers lacked bounded body limits.
3. **Functional Regressions & Doc Drift**: `harness.mjs --pwa` set `args.mode = "pwa"` causing `INVALID_MODE` failure; `--feed-proxy` hung non-proxy HTTP routes in `routes/sse.mjs`; multiple unsupported HTTP method branches returned `true` without sending `405`; `routes/mcp.mjs` omitted `import crypto from "node:crypto"`; `generate-pwa.mjs` / `install-pwa.mjs` failed symlink `bin` checks; `04-edit-element-selector.js` called nonexistent `HTMLReportAgent.getConfig()`; `publishProject()` dropped `customTheme` and `pwa`; `edit-dock.html` had a `{ {` CSS typo; and docs still referenced `--offline`, port `3000`, and legacy test paths.

2. **Studio Server & Route Hardening (`@html-report/studio`)**: Uniform `enforceLocalBridgeSecurity` + `applyLocalCorsHeaders` + `readRequestBody` (`2 MB` cap) across mutating routes, `try/catch` URL decoding in [server.mjs](file:///home/eta/projects/html-report/packages/studio/scripts/server.mjs), pre-lookup `404` dotfile guard and Markdown viewer XSS escaping in [static.mjs](file:///home/eta/projects/html-report/packages/studio/scripts/routes/static.mjs), and escaped Studio UI sinks.
