1. Feature Beneficiary: User-Facing vs. Agent-Facing

Every capability in this platform must clarify who it serves: human developers/readers or autonomous AI coding agents.

Beneficiary Taxonomy
User-Facing Human-Centric

Prioritizes visual clarity, interactive delight, aesthetic DaisyUI styling, WYSIWYG editing, and zero-coding accessibility.

Examples:
  • Creation Studio GUI (create.html)
  • Quill WYSIWYG rich text modal
  • DaisyUI 32-theme switcher
  • Mermaid [⤢ Enlarge] diagram zoom
  • A4 Print and PDF download buttons
Agent-Facing Agent-Centric

Prioritizes headless CLI automation, token efficiency (~70% savings), deterministic speed (<100ms), and schema-validated contracts.

Examples:
  • Semantic <main> fragment injection
  • Deterministic build CLI (build-report.mjs)
  • Mechanical pre-flight auto-repairs
  • JSON status API (GET /__agent_status__)
  • Turnkey reconnect prompt synthesizer
Hybrid Loop Human + Agent

Bridges human visual inspection with agent editing capabilities, creating a seamless co-design feedback loop.

Examples:
  • Edit Mode Dock (#edit-dock)
  • Element Selection Canvas (TargetElement)
  • Two-Way Agent Bridge (window.HTMLReportAgent)
  • Staging Task Queue for agent prompt dispatch

2. The Two Orthogonal Axes: Serving Mode vs. Behavioral Mode

Hosting is NOT the same thing as interactivity. A static file can still fetch dynamic APIs!

2x2 Matrix
Serving Mode \ Behavioral Mode Passive / Printable (Fixed Document) Interactive / Reactive (Dynamic App)

file:///, S3, GitHub Pages
Zero server process required
A. The Paged Document (@html-print)

Invoices, compliance audits, receipts. Fixed layout with @page sizing and .break-inside-avoid. Zero network needed.
B. The Standalone Interactive App (@html-report)

Single portable file fetching public CORS APIs (PokéAPI, OpenMeteo weather), sorting Grid.js tables, animating Chart.js, switching DaisyUI themes via Alpine.js. 0 backend server required!
Server-Connected
localhost:3000 (serve-report.mjs)
Active Node dev server process
C. Dev Print Preview

Live previewing page breaks on port 3000 while editing markdown before running headless Playwright PDF export.
D. The Living Cockpit (@html-dashboard)

Persistent SSE hypermedia streaming via Datastar, subagent swarm hierarchy, hot-reloading on disk changes, and bidirectional agent action dispatcher.

Assembly vs. Pipeline

Assembly is the pure mechanical join putting pieces together fast and reliably (<100ms). Pipeline is the surrounding state machine ensuring speed, pre-flight normalizations, and correctness.

Goal-Driven Archetypes

Each archetype knows what it needs to become (@html-report, @html-dashboard, @html-print, etc.), supported by tailored assembly and pipeline configurations.

Draft vs. Published

Edit Mode is where adjustments happen on an in-flight product. A Published Document is finalized: edit-mode is pruned away, leaving pure content and viewer tools.
