Our Four Core Architectural Tenets

Designed specifically to maximize determinism and reliability across all model tiers

Design Philosophy
Zero Package Manager

Zero npm/pnpm installs. Uses only native Node.js (node:fs, node:path, node:child_process). No dependency bloat, no setup failures in agent environments.

Small-Model First

Designed so less capable models (Flash-Lite, local open-weight LLMs) succeed on attempt 1 with a single command and unambiguous error instructions.

Mechanical Auto-Fix

Trivial mechanical mistakes (stripping accidental <html>/<body> wrappers, slugifying missing heading IDs) are cured automatically in <1ms before compiling.

Agnostic & Blazing Fast

Sub-2ms cold start preserving agent tool latency. Works uniformly across Claude Code, Gemini CLI, Cursor, Antigravity, and headless bash runners.

"Spoon-Fed" Error-as-Instruction Payload

Less capable models cannot interpret raw Playwright headless traces. The harness gives them a literal, copy-paste instruction: 

{
  "status": "REMEDIATION_REQUIRED",
  "attempt": 1,
  "maxAttempts": 3,
  "failureType": "HORIZONTAL_OVERFLOW",
  "culprit": {
    "selector": "#performance-matrix",
    "viewport": "640px (sm)"
  },
  "instruction_for_agent": "Wrap #performance-matrix in <div class=\"overflow-x-auto w-full\"> then re-run."
}

Zero-Penalty Mechanical Auto-Fixes

Why fail a smaller model for mechanical syntax oversights? The harness cures them automatically:

  • Automatic Wrapper Stripping:

    If the model accidentally generates <!DOCTYPE html><html><body>, the harness strips the shell and keeps the inner semantic tags.

  • Auto-Slugified Heading IDs:

    If the model writes <h2>Executive Summary</h2> without an ID, the harness injects id="executive-summary" automatically for the TOC.

  • Single-Command Execution:

    Model only runs: node scripts/harness.mjs run --content fragment.html --title "Title". Zero multi-step cognitive load.
