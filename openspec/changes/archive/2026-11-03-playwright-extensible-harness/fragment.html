Implement the OpenSpec change `playwright-extensible-harness` to refactor the monolithic Playwright verifier into a modular, pluggable test harness with a deterministic CDN Styleguide Matrix and precision CLI flags.

### 1. Primary Goals of this Feature
- **Give the Code Love & Better Organization**: Refactor the monolithic 658-line procedural script into clean, single-responsibility modules: orchestrator (`runner.mjs`), check catalog (`registry.mjs`), diagnostic output engine (`reporter.mjs`), and focused check modules.
- **Maximum Extensibility**: Decouple check authoring using the Strategy and Registry patterns so new CDN libraries, visual audits, or custom plugins can be added in isolated files with zero modifications to the core runner.
- **Dedicated CDN Styleguide Flags**: Provide granular CLI flags (`--all-cdns`, `--cdns <list>`, `--check-<cdn>`) enabling developers to test specific CDN libraries and verify their visual/behavioral styleguides deterministically.
- **Universal Quality & Determinism**: Replace arbitrary sleeps with explicit ready predicates, eliminate flaky assertions, and enforce publication-grade quality (e.g. DaisyUI color sync, zero 403 tile responses, zero unparsed LaTeX syntax leaks).
- **Sub-Second Feedback for Developers & AI Agents**: Allow targeted runs (e.g. `--check-mermaid` or `--suites themes`) in under 800ms rather than waiting 30 seconds for full-suite cycles, and emit machine-readable `--json` traces for automated agent self-healing.
- **100% Backward Compatibility**: Ensure existing CLI invocations (`--quick`, `--pdf`, `--mode`, `--caller`) function identically as a transparent facade.

### 3. Architectural Design Patterns (Mandatory)
1. **Strategy Pattern (`harness/checks/*`)**:
   Implement standard `VerificationCheck` contract with `id`, `name`, `category`, `cliFlags`, `styleguideRules`, and `async run({ page, browser, reportUrl, options, reporter })`.
2. **Registry Pattern (`harness/registry.mjs`)**:
   `CheckRegistry` indexing core checks and CDN styleguide checks; filters dynamically by `--suites`, `--grep`, `--all-cdns`, `--cdns`, and `--check-<cdn>`.
3. **Pipeline with Bail (`harness/runner.mjs`)**:
   Sequential execution pipeline with Template Method execution timing, per-check `--timeout` bounds, and fail-fast termination on `--bail`.
4. **Observer / Reporter Pattern (`harness/reporter.mjs`)**:
   Decoupled lifecycle event logging for clean terminal ANSI output, machine-readable JSON reports (`--json <path>`), and screenshot captures (`--screenshots [dir]`).
5. **Facade Pattern (`verify-report.mjs`)**:
   100% backward-compatible root CLI maintaining legacy arguments (`--quick`, `--pdf`, `--mode`, `--caller`) delegating to `runner.mjs`.

### 4. Deterministic CDN Styleguide Matrix (`harness/checks/cdns/`)
Implement deterministic visual and behavioral checks for all 10 CDN libraries:
- `charts.mjs`: Chart.js canvas render, DaisyUI CSS variable palette sync (`--p`, `--s`, `--a`, `--n`), responsive resize, zero NaN artifacts.
- `mermaid.mjs`: SVG diagram render, DaisyUI theme re-render, strict absence of `"Syntax error in text"` or error SVGs.
- `leaflet.mjs`: Leaflet panes loaded, tile decoding (`naturalWidth > 0`), zero 403 HTTP errors (preventing unauthenticated OSM/Carto tile blocks; enforces ESRI/Voyager).
- `gridjs.mjs`: Table DOM rendered, functional search input, pagination controls, zero horizontal scrollbar container overflow.
- `katex.mjs`: Formatted `.katex` blocks, zero unrendered LaTeX syntax markers (`$`, `\begin{...}`) leaking into DOM text.
- `highlight.mjs`: Code blocks parsed with language classes, `.hljs-keyword` present, DaisyUI theme contrast.
- `marked.mjs`: Clean semantic HTML headings/paragraphs, zero raw `###` or unparsed markdown syntax.
- `lucide.mjs` & `alpine.mjs`: All `[data-lucide]` replaced with SVGs; Alpine `[x-data]` mounted without hanging `x-cloak`.
- `fullcalendar.mjs`: Calendar grid rendered, toolbar formatted, event items mounted.

### 5. Mitigating Ground Rules
- Keep check modules lean and under 70 lines of clean plain JavaScript.
- Batch DOM inspections during full runs (`--all-cdns`) to avoid CDP wire latency spikes.
- Do NOT break existing tests or legacy flags (`--quick`, `--pdf`).

1. Strategy Pattern
harness/checks/*

Every core check and CDN validator is an isolated concrete Strategy implementing a universal VerificationCheck contract. Adding a new CDN takes 1 isolated file with zero runner modifications.

2. Registry Pattern
harness/registry.mjs

A centralized catalog that indexes all checks by ID, category, and CLI flags. Resolves active checks effortlessly based on --suites, --grep, or --check-<cdn>, and allows dynamic plugins.

3. Pipeline with Bail
harness/runner.mjs

Executes checks sequentially through a shared Chromium browser context. Implements Template Method timing, timeout bounds per check, and fail-fast --bail abortion on the first regression.

4. Observer / Reporter Pattern
harness/reporter.mjs

Checks never pollute standard output. They emit lifecycle events (start, pass, fail) received by modular listeners: ConsoleReporter, JsonReporter, and ScreenshotReporter.

5. Facade Pattern
verify-report.mjs

The public entrypoint provides a unified interface maintaining 100% backward compatibility for legacy workflows (--quick, --pdf, --caller) while delegating to the new pipeline.

Universal Quality Contract
Deterministic Schema

All checks return normalized data: { id, passed, durationMs, styleguide: { compliant, rulesChecked }, errors, warnings }, eliminating flakiness and enabling AI agent auto-repair.

Precision CLI Flags Specification

Granular controls for developers, CI runners, and autonomous AI agents

Flag Type Default Description & Purpose
--timeout <ms> Integer 30000 Maximum wait time for navigation, selector waiting, and report readiness handshake.
--all-cdns Boolean false Executes full deterministic styleguide verifications across all 10 CDN libraries.
--cdns <list> Comma string auto Runs styleguide checks on specific CDNs (e.g. --cdns mermaid,charts,leaflet).
--suites / --only Comma string all Runs only specified check suites (e.g. core,cdns,responsive,themes).
--grep <pattern> RegExp null Executes only checks or assertion steps matching the provided pattern.
--themes <list> Comma string all Tests specific DaisyUI themes (e.g. light,dark,cyberpunk,nord) rather than cycling 32 themes.
--viewports <list> Comma string all 5 Verifies named breakpoints (sm,md,lg,xl,2xl) or custom dimensions (e.g. 1920x1080).
--screenshots [dir] Path null Captures PNG snapshots for every tested breakpoint or immediately upon test failure.
--bail Boolean false Aborts the run immediately on the first failed check for rapid CI failure feedback.
--strict Boolean false Treats horizontal space warnings (data-insufficient-space) and console warnings as fatal errors.
--json <path> Path null Emits a structured JSON test execution report with failure traces and durations for agent diagnosis.
--color-contrast Boolean false Runs automated WCAG AA color contrast ratio audits on active themes.
--headed Boolean false Launches Chromium in visible UI mode for interactive visual inspection and debugging.
--quick / -q Boolean false Legacy shorthand: runs sm and lg breakpoints on light theme only without PDF export.
