Code Dive Findings & Philosophy Alignment

Inspecting serve-report.mjs, mcp-server.mjs, domain-model.mjs, and template-shell.html revealed why a minimal Streamable HTTP upgrade on the existing server fits the platform's Pipeline + Two-Way Agent Bridge architecture cleanly without touching mechanical Assembly or Published Document invariants (see proposal.md and design.md).

1. Legacy SSE Transport & Wildcard CORS

serve-report.mjs

serve-report.mjs only exposes the two-endpoint 2024-11-05 transport (/mcp/sse + /mcp/messages) with Access-Control-Allow-Origin: * and no loopback/Host/Origin checks, while handleMCPRequest() always emits a JSON-RPC body even for notifications lacking an id.

2. Disconnected Live Hooks & Stubbed State

mcpContext

mcpContext.getActiveCards() returns hardcoded placeholders, and setTheme/appendAlert only broadcast to datastarClients targeting #theme-runtime-hook (absent in template-shell.html), missing standard reports connected to /__live_reload__ (sseClients + Idiomorph).

3. Bounded Context & Two-Axis Fit

domain-model.mjs

Lives squarely in Pipeline + Two-Way Agent Bridge (Server-Connected × Interactive / Reactive). Assembly (<100ms) stays mechanical, Published Document stays static, and SKILL.md stays <5KB.

4. Zero Breakage to AI Bridge & Turnkey

Additive

HTMLReportAgent, getReconnectPrompt(), /__agent_action__, and /__agent_edit__ handle browser-to-agent requests and remain unchanged; POST /mcp handles agent-to-browser requests on the same :3031 process.
