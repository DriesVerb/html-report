Current Friction & Workspace-First Architecture

Details in proposal.md & design.md

1. Split Folder Input & Create Button

create.html

Currently, Project folder name (#input-project-slug) is nested inside Describe what you want to build, while Create Workspace (#btn-scaffold-now) sits at the bottom of Step 6. Moving both into a dedicated section directly between What are you building? and Describe what you want to build establishes the project workspace up front.

2. Generic _uploads vs. Workspace Refs

serve-report.mjs

POST /api/create/upload currently stages files into projects/_uploads/, and GET /api/create/workspace-files ignores the active project folder. With an active workspace, uploads write straight to projects/<slug>/refs/ and files already inside projects/<slug>/ are automatically included under Does it need to be built on the basis of....
