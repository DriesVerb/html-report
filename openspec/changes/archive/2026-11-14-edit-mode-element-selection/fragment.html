Problem & Vision

Reviewing rich analytical reports produces targeted edits on specific components: reword a KPI heading, alter chart dimensions, modify table columns. Describing these locations in freeform text is ambiguous and slow. Adding an in-dock [⌖ Select] button lets readers click any visual component on screen to bind its exact #id directly to an edit task without reflow, complex overlays, or node_modules.

Key Architectural Highlights

  • Zero Reflow Hover: Uses GPU-accelerated filter: invert(1) hue-rotate(180deg) on hovered elements, ensuring no layout shifts or geometry changes.
  • Hover Only in Selection Mode: Normal browsing is completely untouched; hover filters and crosshairs activate strictly when selection mode is enabled.
  • Just-in-Time Semantic IDs: Automatically generates and stamps unique, human-readable IDs (e.g., #h2-revenue-trends) on click if an element lacks an ID.
  • No Autofill Clutter: Keeps task title and description fields empty for user typing, displaying an isolated dismissible target chip.

Agent Bridge Integration

  • Deterministic Output: buildEditPrompt() automatically prepends Target Element: #id (<tag>) to task prompts.
  • High AI Precision: Code assistants can immediately pinpoint the exact element in content fragments without searching or guessing.
  • Keyboard Ergonomics: Pressing Escape at any moment cleanly dismisses selection mode and restores normal interactions.
