Confirmed Architectural Decisions

Core foundations aligned during brainstorming

D1: Hybrid Input Formats CONFIRMED (A)

Accepts standard DaisyUI JSON configuration objects (themes: [ { "mytheme": { ... } } ]) with automatic sRGB → OKLCH conversion and content auto-contrast, alongside direct raw [data-theme="..."] CSS blocks.

D2: In-Browser Theme Studio CONFIRMED (A)

A dedicated "Customize Theme" modal accessible from the navbar theme dropdown. Features live interactive color pickers, real-time Chart.js/Mermaid diagram updates, localStorage persistence, and one-click copy to DaisyUI CSS & Tailwind config.

D3: Pure JS Matrix Math CONFIRMED (A)

Zero-dependency inlined color conversion math (sRGB → Linear → XYZ → OKLab → OKLCH) executing in <1ms without external CDN dependencies or bundle bloat.

D4: Base Theme Inheritance CONFIRMED (A)

Themes can declare "extends": "dark" or "extends": "emerald" to inherit all base surface, neutral, and geometry tokens while overriding only specific branding colors.
