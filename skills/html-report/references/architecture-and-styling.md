# HTML Report Fragment Architecture, Addons & Component Recipes

Agents author **only the Semantic Fragment** (`<section>` blocks injected into `<main id="report-main">`). `build-report.mjs` deterministically wraps the fragment in `template-shell.html` and injects required addons.

## 1. Shell Invariants (Handled by `build-report.mjs` — Never Emit in `<main>`)

- **Document Head & Core 4 CDNs**: `<!DOCTYPE html>`, `<html lang="en" data-theme="light" data-report-mode="...">`, inline emoji SVG `<link rel="icon">`, Tailwind CSS Play CDN (without `crossorigin`), DaisyUI 4 (32 themes), Lucide Icons, and Alpine.js are injected automatically.
- **Sticky DaisyUI Navbar (`print:hidden`)**: Left `#navbar-report-title` + `#navbar-mode-badge`; right `#toc-dropdown` (auto-maps `h1`/`h2`/`h3` headings with `id` attributes) and `#settings-dropdown` (32-theme swatch picker, HTML/PDF export, Edit Mode dock, and AI Agent Bridge).
- **Runtime & Footer**: `report-runtime.js` (OKLCH canvas color resolver, TOC builder, `window.checkInsufficientHorizontalSpace()` detector) and the centered `generated by html-report` footer are provided by `template-shell.html`.
- **Optional Print Cover (`--mode print`)**: If `#print-cover-page` is used, keep `class="hidden print:flex"` so it never renders on screen.

## 3. Canonical `<main id="report-main">` Component Recipes

### 3.1 Responsive Card Header (Flex Boundary & Badge Protection)
Always pair `min-w-0 flex-1` on text columns with `shrink-0 whitespace-nowrap` on badges/buttons so long titles never push actions outside cards:
```html
<div class="card bg-base-100 border border-base-300 shadow-sm p-5 space-y-3">
  <div class="flex flex-wrap sm:flex-nowrap justify-between items-center gap-3 w-full">
    <div class="min-w-0 flex-1">
      <h2 id="section-title" class="text-lg font-bold break-words">Section Heading</h2>
      <p class="text-xs text-base-content/70 break-words">Concise section summary</p>
    </div>
    <span class="badge badge-primary badge-outline text-xs font-mono shrink-0 whitespace-nowrap">Verified</span>
  </div>
</div>
```

### 3.2 KPI Stats Grid

### 3.3 Horizontal Stepper (Never Use `sm:steps-horizontal`)
Tailwind Play CDN does not generate responsive variants for DaisyUI classes (`sm:steps-horizontal` is ignored). Always use `steps-horizontal` inside `overflow-x-auto`:
```html
<div class="w-full overflow-x-auto">
  <ul class="steps steps-horizontal w-full min-w-[500px] text-xs font-semibold">
    <li class="step step-primary" data-content="✓">Brainstorming</li>
    <li class="step step-primary" data-content="●">Planning</li>
    <li class="step" data-content="3">Implementing</li>
    <li class="step" data-content="4">Verifying</li>
    <li class="step" data-content="5">Shipped</li>
  </ul>
</div>
```

### 3.5 Showdown Markdown Artifact Trigger & Guardrails
Wire `.md` mentions to `openMarkdownViewer('file.md')` backed by `#open-spec-artifacts-data`:
```html
<button type="button" onclick="openMarkdownViewer('proposal.md')" class="btn btn-sm btn-outline gap-1.5">
  <i data-lucide="file-text" class="w-4 h-4"></i><span>proposal.md</span>
</button>
<script id="open-spec-artifacts-data" type="application/json">
{ "proposal.md": "# Proposal\n\nMarkdown content rendered in modal." }
</script>
```
- **SVG & Mermaid Guards**: Never nest Alpine `<template x-for>` inside `<svg>` (use `<div class="grid">` with per-item `<svg>`). In Mermaid node labels, quote special characters and avoid `"1. "` numbered list prefixes (`Step 1 - Intake`).
- **Leaflet Tiles**: Use Esri ArcGIS tiles (`https://server.arcgisonline.com/ArcGIS/rest/services/World_Street_Map/MapServer/tile/{z}/{y}/{x}`) to prevent `file://` 403 blocks.
