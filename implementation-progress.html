          Feature 1
          
Bidirectional HTML ↔ Agent Interactive Loop

        

        

           IMPLEMENTED
          Datastar SSE + Multi-turn Session
        

      


      

        
        

          

            
PO

            

              
Product Owner Vision

              
User Persona: Analytical Lead / Executive

            

          

          

            “Users feel trapped when looking at static reports. When an executive spots an anomalous trend in a Q3 revenue chart, they shouldn't have to copy numbers into a chat window. They want to click that chart, type 'Why did churn spike here? Recompute assuming 10% lower retention', and have the AI re-render the chart and table right in front of them.”
          

          

            
 Inline floating prompt bar (Cmd+K)

            
 Contextual 'Ask Agent' button on every card

            
 Non-destructive, in-place DOM fragment morphs

          

        


        
        

          

            
TL

            

              
Tech Lead Architecture

              
Engine: Datastar SSE + agy CLI Streaming

            

          

          

            “We already have /__datastar_stream__. To make this two-way, the browser sends POST /api/agent/prompt with serialized element context. We stream tokens from agy CLI and emit datastar-merge-fragments. Crucially: any mutating file or git operation must render an approval card requiring explicit human confirmation.”
          

          

            
 Multi-turn SessionState in dev server memory

            
 10KB DOM context serialization cap to prevent bloat

            
 Interactive Human-in-the-Loop action approval cards

          

        

      

    


    
    

      

        

          Feature 2
          
Two-Way MCP (Model Context Protocol) Server & Client Gateway

        

        JSON-RPC 2.0 over SSE + Local CSRF Guard
      


      

        

          

            
PO

            

              
Product Owner Vision

              
Standardization: Open Model Context Protocol

            

          

          

            “MCP is the universal standard for AI tools across Anthropic Claude, Cursor, and Antigravity. If our dev server runs as an MCP Server, any external agent can treat our report as a rich visual screen! If it runs as an MCP Client, dashboard widgets can fetch real database rows from Postgres MCP without building custom backends.”
          

        


        

          

            
TL

            

              
Tech Lead Architecture

              
Protocol: JSON-RPC 2.0 SSE Transport

            

          

          

            “Security is non-negotiable. Allowing a browser to trigger local MCP tools means malicious external websites could probe localhost:3000. We will enforce: (1) Localhost origin verification, (2) Ephemeral cryptographic CSRF tokens generated at server boot, and (3) An explicit mcp_allowlist.json.”
          

        

      

    


    
    

      

        

          Feature 3
          
Modular Skill Decomposition (Matt Pocock Pattern)

        

        Monorepo Engine + Thin Specialized Facades
      


      

        

          

            
PO

            

              
Product Owner Vision

              
UX: Laser-Focused Agent Skills

            

          

          

            “Matt Pocock showed that agent skills work best when they do ONE thing with extreme precision. When a user asks for a printable PDF, loading instructions for Datastar hypermedia and Impress 3D transitions creates prompt bloat and confusion. We need html-report, html-print, html-dashboard, html-presentation, and html-pwa.”
          

        


        

          

            
TL

            

              
Tech Lead Architecture

              
Pattern: Shared Monorepo Facade Engine

            

          

          

            “Splitting skills is brilliant, but duplicating scripts across 5 repositories would be catastrophic. We will use the **Facade Pattern**: Keep one unified deterministic core engine in skills/html-report/scripts/, and expose 5 lightweight (<5KB) SKILL.md facades that reference the shared CLI.”
          

        

      

    


    
    

      

        

          Feature 4 & 4.1 → Feature 3
          
Creation Studio (/html-create & /html-create:cli) Integrated into Skill Suite

        

        Domain Modeling & Sibling Routing
      


      

        

          

            
PO

            

              
Product Owner Vision

              
Experience: Action-Oriented Creation Commands

            

          

          

            “Renaming this capability from passive 'help' to /html-create and /html-create:cli aligns perfectly with what users actually want to do: build! And when Feature 4 is completed, it must be added straight into Feature 3's modular skill suite as the master creation front-door skill!”
          

          

            
 /html-create: Rich interactive browser studio

            
 /html-create:cli: Fast terminal interview

            
 Automatic routing to @html-print, @html-dashboard, etc.

          

        


        

          

            
TL

            

              
Tech Lead Architecture

              
Skill Facade: skills/html-create/SKILL.md

            

          

          

            “This creates a unified creation entrypoint. Feature 4 delivers the domain engine and terminal script. Feature 3 houses the skill definition. When the user completes the wizard or CLI grill, the engine outputs the deterministic prompt targeting the exact sibling skill with zero token bloat.”
          

          

            
 Lightweight ~3.5KB SKILL.md in .agents/skills/html-create/

            
 Dual trigger: slash command or interactive node script

            
 Seamless fallback alias for legacy /html-help

Product Owner (PO) Lens

          
Conversion, Personas & Business Value

        

      

      

        

          × The Jargon Trap: High-intent users (executives, business analysts, non-engineers) abandon creation flows when confronted with terms like “Offline PWA”, “One-Way SSE Push”, or raw library acronyms.
        

        

          ✓ Value-Driven Taxonomy: Frame every option around Jobs-to-be-Done:
        

        
    
          
  • Executive: Needs high-level confidence (“Can I read this on an airplane?” → Downloadable as an App).
    • 
          
  • Data Lead: Needs clear deliverables (“Can I show sales trends and export data?” → Interactive Charts & Data Tables).
    • 
          
  • AI Engineer: Needs deterministic prompts and reproducible CLI flags with zero token waste.
    • 
        

      

      
100% Outcome-Based Framing

    


    
    

      

        

          
        

        

          
UX Designer Lens

          
Cognitive Load & Mental Models

        

      

      

        

          • Mental Model Translation: Users don't care about Service Workers or Server-Sent Events; they care about what the artifact can do:
        

        

          
“Offline PWA” → “Downloadable as an App”

          
“One-way SSE” → “Live Data Feed (View-Only)”

          
“Two-way agent loop” → “Interactive AI Assistant”

          
“Chart.js / Grid.js” → “Charts & Data Tables”

        

        

          • Progressive Disclosure: The end product includes 32 themes baked in. Never force hex color pickers upfront! Offer standard themes by default, and tuck custom corporate branding into an optional drawer.

UI Designer Lens

          
Affordances, States & Live Simulation

        

      

      

        

          • Rich Selection Cards: Touch-friendly cards with distinct icons, clear labels, explanatory subtext, and active accent borders provide instant feedback.
        

        

          • Real-Time Live Wireframe Preview: Instead of asking users to imagine what their choices produce, the right column features a live wireframe mockup that dynamically renders the mock navbar, widgets, and AI dock in real-time as options are toggled!
        

        

          • Dynamic Pruning & Badging: If “Printable PDF” is selected, incompatible real-time server features are gracefully disabled with helpful contextual tooltips.
